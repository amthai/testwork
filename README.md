# Proof

Proof помогает дизайнеру тренироваться защищать тестовое задание в голосовом разговоре с командой AI-интервьюеров. В режиме DeepSeek приложение распознаёт русскую речь с помощью GigaAM, озвучивает интервьюера через Яндекс LiveTTS (в локальной конфигурации доступен Piper) и передаёт текст и выбранные кадры экрана в DeepSeek Flash. Также поддерживается режим OpenAI Realtime.

Денис ведёт встречу. После показа решения в разговор могут вступить продакт-менеджер Марина, CPO Ирина и системный аналитик Сергей. Состав вопросов зависит от задания работодателя и рассказа дизайнера. Характер и правила каждого интервьюера редактируются в его файле. [Профили команды и ход защиты](docs/product/design-lead.md) · [Профиль дизайн-лида](src/lib/roles/design-lead.ts).

## Запуск

Требуется Node.js 24. Сервер читает секреты из игнорируемого `.env.local`; имена настроек перечислены в `.env.example`. Для режима DeepSeek нужны ключ DeepSeek и работающий речевой сервис. [Настройка и запуск](docs/technical/setup-local.md#локальная-речь-и-deepseek).

```bash
npm ci
npm run dev
```

Frontend: http://localhost:5173, backend: http://127.0.0.1:3001. `npm run dev` запускает оба процесса.

```bash
npm test
npm run build
npm start
```

`npm start` отдаёт API и собранный frontend на порту 3001. При самостоятельном запуске задавай соответствующий `APP_ORIGIN`.

## Доступ и production

Рабочий сайт доступен по приглашению. [Открыть Proof](https://proof.uisamurai.ru/)

В production требуется HTTPS и код доступа. `npm run setup:access` создаёт случайный код в игнорируемом `.env.local`, сохраняя существующие настройки и не печатая секрет. Код предназначен организатору для выдачи участникам. Это версия для доступа по приглашению; платежи и аккаунты между устройствами не подключены.

`npm run check:openai` выполняет минимальный реальный запрос и отличает пустой баланс от временного ограничения запросов. Команда расходует небольшое число API-токенов. Полный голосовой прогон проводится отдельно.
