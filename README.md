# Proof

Proof — прототип тренировки защиты дизайнерского тестового задания в формате реального созвона с AI-интервьюером.

## Локальный запуск

```bash
npm install
npm run dev
```

Для production-сборки:

```bash
npm run build
```

Проект работает без ключей в mock-режиме. Локальные переменные можно задать в `.env.local` по образцу `.env.example`.
