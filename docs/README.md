Документы разделены по назначению:

| Раздел | На какой вопрос отвечает |
|---|---|
| `product/` | Что строим, для кого и что входит в текущий scope |
| `technical/` | Как проект устроен, запускается и деплоится |

## Как синхронизировать документы

1. Измени постоянный документ, если поменялось текущее поведение проекта.
2. Для заметного решения, фикса, фичи, теста или инфраструктурной работы создай одну knowledge-запись.
3. Добавь запись в начало `knowledge/INDEX.md`.
4. Для бага синхронно обнови `knowledge/bugs.md`.
5. Если изменение заметно пользователю, добавь краткий пункт в корень `CHANGELOG.md`.

Журнал не заменяет текущую документацию: он хранит контекст и историю, а не второй вариант спецификации.
