# Локальная разработка

## Требования

- Node.js с поддержкой ESM и npm;
- браузер с поддержкой `getUserMedia` и `getDisplayMedia` для проверки media-сценариев.

Точная версия Node.js для локальной среды должна совпадать с версией, выбранной в `Dockerfile` или CI.

## Установка и запуск

```bash
npm install
npm run dev
```

Vite выведет локальный адрес dev-сервера. Для ручной проверки screen share используй защищённый origin или `localhost`.

## Переменные окружения

Шаблон находится в `.env.example`:

- `VITE_AI_PROVIDER=mock` — текущий безопасный режим без внешних credentials;
- `VITE_BASE_PATH=/` — базовый путь Vite-сборки при необходимости размещения не в корне.

Секретные значения, включая будущий `OPENAI_API_KEY`, нельзя помещать в переменные с префиксом `VITE_` и нельзя добавлять в клиентский код. Локальные значения хранятся только в `.env.local`, который игнорируется Git.

## Проверки

Production-сборка одновременно запускает TypeScript-проверку и Vite build:

```bash
npm run build
```

Если появится отдельный test/lint runner, его команды нужно добавить сюда и в `docs/qa/README.md`.
