# Темп перелива логотипа

Время кадра приходит из requestAnimationFrame в миллисекундах. Деление по модулю 32 повторяло рисунок каждые 32 мс. После исправления единиц времени цикл занимал 90 секунд. По просьбе пользователя период уменьшили до 50 000 мс. За это время Evolution равномерно проходит от 0 до 100 процентов.

На локальной главной во встроенном браузере сравнили кадры логотипа через несколько секунд. Блики смещаются внутри контура букв. Сборка прошла.
