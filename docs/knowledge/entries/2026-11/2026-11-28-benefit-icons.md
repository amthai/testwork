# Иконки преимуществ на главной

В плашках использованы три локальных SVG из [каталога Heroicons Fill в Morphicons](https://github.com/guillermolg00/morphicons/blob/main/website/lib/icon-sets/heroicons-fill.ts). Облако диалога, экран и лампочка дополняют текст, поэтому у изображений пустое альтернативное описание. Лицензия сохранена в `public/licenses/heroicons.txt`.

Во встроенном браузере все три SVG загрузились и отобразились по центру тёмных плашек рядом со своими подписями. Сборка `npm run build` прошла.

После смены цвета проверили заливку всех контуров в собранных SVG с учётом наследования от группы. У всех трёх иконок цвет `#E3F0FF`.

По просьбе пользователя вернули белый цвет. После повторной сборки все контуры трёх SVG имеют заливку `#fff`.

Иконку монитора заменили на стопку слайдов (Heroicons Fill, `square-3-stack-3d-solid`). Сплошная верхняя плоскость придаёт ей визуальный вес рядом с облаком диалога и лампочкой. Проверили все три плашки рядом во встроенном браузере. Сборка прошла.

Все три плашки перевели на [Heroicons Outline из Morphicons](https://github.com/guillermolg00/morphicons/blob/main/website/lib/icon-sets/heroicons-outline.ts). У диалога, стопки слайдов и лампочки белая линия толщиной 1,5 px при размере иконки 24 px. Во встроенном браузере проверили три контура рядом с подписями. Сборка прошла.

Во вторую плашку вернули монитор из Heroicons Outline (`computer-desktop`). Проверили во встроенном браузере белую обводку рядом с диалогом и лампочкой. Сборка прошла.

Для трёх плашек выбрали одну серию Light из бесплатного набора Iconly Essential. Chat с тремя точками обозначает тренировку ответов, Show — взгляд на рассказ глазами слушателя, Activity — улучшение работы. Взяли SVG из бесплатной выдачи веб-приложения Iconly, изменили цвет обводки на белый. [Условия автора для Essential](https://piqodesign.gumroad.com/l/iconly) разрешают коммерческое использование. Ссылку на источник сохранили в `public/licenses/iconly.txt`. Во встроенном браузере проверили все три иконки рядом с подписями. Сборка прошла.

Перешли на залитые варианты Chat, Show и Activity из бесплатной серии Iconly Bulk. Крупные формы белые, второй цвет — #858585 со 100% непрозрачностью. Проверили все три плашки во встроенном браузере. Сборка прошла.

Для тренировки ответов выбрали микрофон Voice, для проверки рассказа и презентации — лист со строками Document. Оба SVG из Iconly Bulk используют белую заливку и детали #858585. Проверили весь ряд плашек во встроенном браузере. Сборка прошла.

Для показа презентации Document заменили на Play из Iconly Bulk. Во встроенном браузере проверили белый круг с серым треугольником во второй плашке. Сборка прошла.

По запросу перешли на Tabler Filled. Для ответов выбрали microphone, для презентации — экран на стойке presentation, для улучшений — chart-dots. В локальных SVG разделили белую заливку и серые детали #858585. MIT-лицензия находится в `public/licenses/tabler-icons.txt`. Проверили весь ряд на главной во встроенном браузере. Сборка прошла.

Пользователь выбрал Tabler microphone для первой плашки и device-desktop для второй. У монитора белый экран и подставка #858585. Проверили во встроенном браузере, сборка прошла.

Для третьей плашки пользователь выбрал Tabler Filled arrow-big-up-lines. Стрелка белая, две линии под ней серые (#858585). Проверили ряд из микрофона, монитора и стрелки во встроенном браузере. Сборка прошла.
