# Круглый индикатор загрузки экранов

При ожидании модуля экрана и списка защит появлялись разные текстовые сообщения. Теперь оба состояния используют общий компонент `ScreenLoader`. Кольцо расположено по центру окна. Скринридеру доступна подпись текущей операции. Вращение включается только при обычной настройке движения.

Во встроенном браузере на локальной сборке проверен переход «Студия» → «Мои защиты». Тестовый сервер по очереди задерживал модуль истории и ответ списка. В обоих состояниях центр индикатора находился в точке (640, 360) при размере окна 1280 × 720. После ответа с пустым списком индикатор исчез и появилось приглашение начать первую защиту.

`npm run build` прошла. Все 98 тестов `npm test` прошли.
