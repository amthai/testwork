# Суточная квота звонков на время тестов

26 ноября в 20:11 по Чите на рабочем Proof отключили суточную проверку числа подключений для тестирования. До изменения на одном профиле было пять попыток из пяти, суммарно на сервере — пять из тридцати. Попытки по-прежнему учитываются за скользящие 24 часа. Квоты загрузки фото, число параллельных звонков и длительность регулируются отдельно.

Использован веб-образ `testwork-proof:0.11.0-test-calls-20261126`. Изменения исходников сохранены в рабочем проекте и релизном каталоге VPS. Для возврата обычного режима установить `DAILY_CALL_LIMIT_ENABLED=true` в серверном окружении и пересоздать веб-контейнер. [Параметры запуска](../../../technical/setup-local.md).

Сборка и 113 тестов прошли. Тест с провайдером-заглушкой подтвердил повторный старт сверх обеих суточных квот. На кандидате и в рабочем контейнере вызов с исчерпанными квотами на изолированной базе дошёл до проверки задания. Платную сессию для проверки не открывали. Перед переключением активных разговоров не было. Копия базы с восемью сессиями прошла проверку целостности, публичный маршрут готовности вернул HTTP 200.
