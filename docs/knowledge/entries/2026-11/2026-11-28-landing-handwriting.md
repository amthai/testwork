# Рукописная фраза над подвалом

Для Rozovii Chulok заданы траектории пера, которые открывают буквы через SVG-маски. Начертание и размеры задаёт исходный шрифт. После последнего штриха остаётся обычный текст. При системном уменьшении движения CSS сразу показывает текст.

Ускорение в 1,3 раза применяется к штрихам и паузам. От первого движения пера до точки вопросительного знака проходит 3,93 секунды.

Во встроенном браузере до прокрутки ни один из 28 штрихов не появился. При переходе к подвалу показался первый штрих, затем остальные буквы и знаки. После прокрутки вверх и обратно готовая фраза осталась на месте. Сборка прошла.
