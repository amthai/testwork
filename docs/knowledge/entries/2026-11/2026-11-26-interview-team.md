# Четыре роли в тренировочной защите

Раньше все вопросы задавал Денис. Теперь он ведёт встречу и может передать слово продакт-менеджеру Марине, CPO Ирине или системному аналитику Сергею. К примеру, неясный статус частичного возврата даёт повод для вопроса аналитика. Экономический эффект обсуждается, если для него есть основание в задании или рассказе. Правила, характер и голоса каждого интервьюера редактируются в его профиле. [Профили команды](../../../product/design-lead.md).

Перед каждой новой темой план содержит автора и дословное основание. Сервер сверяет цитату с исходными материалами, сохраняет автора в журнале и ждёт окончания передачи слова. Уточнение остаётся у автора вопроса. При отсутствии открытых тем команда может перейти к завершению сразу после презентации. Модель получает это же правило при составлении отчёта.

DeepSeek использует отдельные голоса Yandex LiveTTS или Piper. В режиме OpenAI Денис говорит через Realtime, для коллег сервер озвучивает утверждённый текст через Audio Speech API. На звонке, в расшифровке и экспорте показываются имена и должности. Старые расшифровки читаются с прежней подписью Proof, когда имя автора отсутствует.

## Проверка

- Во встроенном браузере на синтетической сессии проверены подпись «Ирина» и должность CPO на звонке, а также автор «Сергей · Системный аналитик» в расшифровке.
- Все 112 автотестов прошли, `npm run build` собрал клиент и сервер. Проверены в том числе окончание без вопросов, неподтверждённое основание, передача слова после воспроизведения, перебивание, повтор и восстановление голоса автора.
- Через локальные HTTP-маршруты четыре реальные модели Piper озвучили один вопрос. GigaAM во всех четырёх случаях распознал его дословно.
- Во встроенном браузере проверены полное воспроизведение тестового MP3 специалиста и остановка при перебивании. Облачные API при этих проверках заменялись тестовыми ответами.
- При экспертном прогоне требуется проверить смысловую связь выбранной роли и вопроса с исходной цитатой. [Сценарии проверки](../../../qa/design-lead-evaluation.md).
