# Публикация Proof 0.11.0 с портретами команды

26 ноября 2026 в 20:03 по Чите опубликован релиз с четырьмя портретами на экране звонка. [Коммит 1828a9f](https://github.com/amthai/testwork/commit/1828a9f) · [Проверка на компьютере и телефоне](2026-11-26-call-portraits.md).

В чистой копии релизного коммита прошли установка зависимостей, 112 тестов и сборка. Аудит выявил четыре замечания уровня moderate. Проверка GitHub собрала образ из штатного Dockerfile. [GitHub Actions](https://github.com/amthai/testwork/actions/runs/45806469613).

На VPS с ограниченным местом использовали рабочий образ приложения 0.10.0 как основу. Сверили зависимости и все 26 скомпилированных серверных модулей, заменили сборку интерфейса и файлы с номером версии. Изолированный экземпляр сохранил доступ и задание после перезапуска.

Обе проверки перед переключением показали ноль активных звонков и формирующихся отчётов. Согласованная резервная копия SQLite с восемью сессиями прошла проверку целостности. Она находится в `/opt/testwork-proof/rollback/0.11.0-20261126/pre-release.sqlite`.

На рабочем сайте совпали контрольные суммы 18 файлов, включая четыре портрета. Маршруты `/health`, `/health/ready` и `/api/bootstrap` вернули HTTP 200. Во встроенном браузере открылся опубликованный портрет Марины. Приложение и служба речи получили статус healthy, число перезапусков у каждой равно нулю. Проверка прошла без расхода платной голосовой квоты.

Для отката из каталога `/opt/testwork-proof/releases/0.10.0-20261126` выполнить `docker compose up -d --no-deps --no-build web`, проверить готовность по HTTPS и вернуть ссылку `current` на этот каталог. Рабочие тома сохраняются.
