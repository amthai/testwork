# Единый профиль дизайн-лида

Правила Дениса находились в общей методологии, обработчике этапов и инструкциях отдельных провайдеров. Например, правка тона в основном разговоре могла пропустить быстрый ответ про задание или реплику после восстановления связи.

Для Дениса собрали задачу, характер, ценности, правила уточнений, реплики и критерии разбора в одном модуле. OpenAI Realtime и DeepSeek используют нужные части профиля при обработке хода. Сервер проверяет лимиты и основания выводов. Следующую роль можно описать в соседнем файле. [Рабочий профиль](../../../../src/lib/roles/design-lead.ts) · [Решение](../../../superpowers/specs/2026-11-26-interviewer-role.md).

## Проверка

- `npm test` — прошли все 99 тестов. На подставных ответах провайдеров проверены инструкции для диалога и планирования, быстрый ответ по брифу, распознавание фото и подготовка отчёта.
- `npm run build` — приложение и сервер собрались. Собранный сервер с базой в памяти ответил на `/health`. Тексты внутренних инструкций входят только в серверную сборку.
