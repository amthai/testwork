# Публикация Proof 0.10.0 с командой интервьюеров

26 ноября 2026 в 19:41:37 по Чите (10:41:37 UTC) сервер переключили на релиз `0.10.0-20261126`. В этой версии Денис может передать слово Марине, Ирине или Сергею. [Коммит `90fad44`](https://github.com/amthai/testwork/commit/90fad44) · [Как работают роли](2026-11-26-interview-team.md).

## Перед переключением

- В чистой копии проекта выполнили `npm ci`, все 112 тестов и `npm run build`. Аудит зависимостей выявил четыре замечания уровня moderate, ни одного уровня high или critical. Собраны релизные образы приложения и службы речи. [Запуск GitHub Actions](https://github.com/amthai/testwork/actions/runs/45802437322).
- На изолированном кандидате после перезапуска сохранились доступ и текст задания. Тестовый план воспроизвёл три передачи слова от Дениса. Проверены четыре реальные модели Piper, распознавание GigaAM и шесть реплик с авторством. По условиям этого прогона платные API не вызывали.
- Две проверки подтвердили отсутствие активных защит и формирующихся отчётов. Проверена целостность резервной копии SQLite с семью сессиями в `/opt/testwork-proof/rollback/0.10.0-20261126/pre-release.sqlite`.

## После переключения

Контрольные суммы всех 13 файлов, полученных по HTTPS, совпали с релизной сборкой. Маршруты `/health`, `/health/ready` и `/api/bootstrap` вернули HTTP 200. Bootstrap показал DeepSeek и Яндекс. Во встроенном браузере на главной странице отображались три специалиста. Обе службы получили статус healthy, число перезапусков у каждой равно нулю.

После проверки удалили временные контейнеры кандидата, его сеть и два тестовых тома. Рабочий сервер повторно подтвердил готовность. На общем диске VPS осталось 3,1 ГиБ свободного места, занято 98%.

## Откат

Сохранить рабочие тома. В каталоге `/opt/testwork-proof/releases/0.9.4-20261126` последовательно восстановить службу речи из образа `proof-speech:0.3.0-20261123` и приложение из `testwork-proof:0.9.4-20261126`. После проверки готовности вернуть ссылку `current` на каталог 0.9.4. [Точные команды](../../../technical/deployment.md#текущий-релиз).
