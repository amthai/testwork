# Живой прогон DeepSeek с русским голосом и кадром

Проверили вымышленную защиту мобильного сценария аптечного самовывоза в изолированной базе. DeepSeek Flash выделил четыре требования из текста брифа. На экране были две аптеки с разным наличием и одна кнопка бронирования. GigaAM распознал презентацию и ответ кандидата. Piper озвучил вопрос о том, что произойдёт при выборе первой аптеки, где товара нет.

## Что исправили

- Модель дважды пыталась оценить предыдущий ответ при переходе к первому вопросу. Теперь DeepSeek получает отдельную схему первого хода. Состояние «ещё не оценивалось» выставляет сервер. Последующие вопросы используют полную схему.
- Первый отчёт сослался на слова интервьюера в разделе сильных сторон. Сервер отклонил этот ответ. Теперь в запросе модель отдельно получает перечень реплик кандидата и кадров, на которые можно опираться при оценке. В подробном разборе собственно вопрос можно цитировать с указанием говорящего.
- Второй отчёт содержал синтаксическую ошибку. Ошибки формата теперь дают понятное сообщение с возможностью повторить запрос. Третий ответ поместил массив вариантов формулировок рядом с разделом подробностей. Сервер принимает оба расположения при единственном корректно заполненном массиве и проверяет каждую цитату. Повторная обработка сохранённого ответа через маршрут отчёта завершилась успешно без дополнительной генерации.

## Результат проверки

В браузере открыли собранный Proof с итогом этой защиты. Видны четыре требования, один переданный кадр, две реплики кандидата и ссылки на цитаты с отметками времени. В отчёте предложено сделать недоступную аптеку неактивной и включать бронирование после выбора аптеки с товаром. Один пограничный вывод остался в отчёте: модель отметила выбор аптеки как подтверждённый, хотя по одному статичному кадру поведение при нажатии проверить нельзя.

По полям использования семи ответов API расход составил около $0,0079 при бюджете $0,05. В расчёт вошли один бриф, три попытки составить план вопроса и три попытки составить отчёт. Применён тариф на время ответов 23 ноября 2026 года, 11:03–11:08 UTC, с учётом кеширования входа. [Тарифы DeepSeek](https://api-docs.deepseek.com/quick_start/pricing/)

Все 71 автоматическая проверка прошла, клиент и сервер собраны. В голосовой сценарий подавали синтезированную речь и тестовое изображение. Физический микрофон, динамики и интерактивный захват экрана в этом прогоне не использовались.
