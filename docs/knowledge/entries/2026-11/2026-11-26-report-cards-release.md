## Проверки

- Локально: npm run build и 98/98 тестов прошли. npm audit --audit-level=high прошёл: 0 high/critical, прежние 4 moderate.
- Образ собран на VPS с чистым npm ci. Секреты, пользовательские данные и локальный QA-стенд не вошли в архив; runtime не содержит .env.local, HTTP-запрос к нему возвращает 404.
- Кандидат proof-qa-083: отдельный том и loopback-порт 4182, сеть действующего speech. /health/ready готов; код доступа, HttpOnly/Secure cookie, сохранение задания и авторизации после перезапуска проверены. Платный AI и новый голосовой звонок не вызывались: серверные файлы неизменны относительно проверенного 0.8.2.
- HTML и четыре файла UI (основной JS, CSS, history и feedback) совпали с выдачей контейнера. История открыта в IAB через временный SSH-туннель.
- До переключения дважды проверено отсутствие live/connecting/finishing: 0. SQLite backup API создал согласованную копию четырёх сессий, PRAGMA quick_check = ok.
- После переключения HTTPS /health и /health/ready вернули 200; bootstrap подтвердил DeepSeek, Yandex и защиту кодом. Все четыре опубликованных UI-ресурса побайтно совпали с локальной production-сборкой.
- Публичная история открыта в IAB: серый фон, белая карточка пустого состояния. Подробный отчёт и мобильная версия проверены до релиза на синтетических данных — см. запись о дизайне.
- Web и speech healthy, restarts=0. Кандидат и его тестовый том удалены, production-том сохранён.
