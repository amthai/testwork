# Публикация «Вслух» 0.11.1

27 ноября в 13:57 по Чите рабочий сайт переключён на [релизный коммит 3b10943](https://github.com/amthai/testwork/commit/3b109437ecc6d5ca61378c8bc2aec1a882116a3b). Отдельный коммит d498eca фиксирует режим суточных квот, который уже действовал на сервере с 26 ноября. Параметры доступа, домен и тома продолжают использоваться с прежними именами.

В чистой копии коммита прошли установка зависимостей, 113 тестов и сборка. Аудит зависимостей выявил четыре замечания уровня moderate, высоких и критических нет. GitHub Actions собрал образ штатным Dockerfile. [Проверка релиза](https://github.com/amthai/testwork/actions/runs/45942638324).

Для экономии места на VPS новые образы собраны поверх действующих образов с теми же зависимостями. В веб-образ вошли обе сборки из чистой копии коммита, в речевой — обновлённые исходники сервиса и уведомление о моделях. В отдельном экземпляре прошли проверка доступа по коду, сохранение задания и повторный вход после перезапуска. Piper озвучил фразу с названием сервиса, GigaAM распознал её. Проверка речи была локальной. Платный созвон с AI в этот релизный прогон не входил.

До переключения дважды проверили, что нет активных звонков и разборов в обработке. Согласованная копия базы из десяти сессий прошла проверку целостности. Снимок хранится в `/opt/testwork-proof/rollback/0.11.1-20261127/pre-release.sqlite`.

После переключения по публичному HTTPS совпали контрольные суммы всех 76 файлов сайта. Маршруты `/health`, `/health/ready` и `/api/bootstrap` вернули HTTP 200. Страница во встроенном браузере показала новое имя, логотип и заголовок. Оба контейнера получили статус healthy, число перезапусков равно нулю. Рабочее окружение сохранило режим тестирования звонков.

Для возврата предыдущей версии в каталоге `/opt/testwork-proof/releases/0.11.0-test-calls-20261126` выполнить `docker compose --profile speech up -d --no-build speech web`. После проверки публичного `/health/ready` вернуть ссылку `/opt/testwork-proof/current` на этот каталог.
