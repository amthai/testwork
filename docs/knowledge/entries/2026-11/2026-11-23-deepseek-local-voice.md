# Локальная русская речь и DeepSeek Flash

## Решение

Для нового режима GigaAM-v3 E2E CTC INT8 распознаёт русский звук, Piper Denis озвучивает утверждённые вопросы. DeepSeek Flash получает текст и изображения для брифа, следующего вопроса и отчёта. Проверка оснований, ограничения количества уточнений и сохранение сессий общие для обоих режимов. Код различает ключи провайдеров. В этой рабочей копии выбран DeepSeek.

Русский словарь произношения используется только для голоса интервьюера. В правила методологии добавлено уточнение неоднозначных терминов. Это особенно важно при работе с Figma, UX и A/B. [Ранний тест моделей](2026-11-23-local-russian-speech.md)

## Проверка

- `npm test` — 69 тестов, включая маршрутизацию брифа, изображений и отчёта, изоляцию голосовых соединений, повторную отправку аудио, прерывания и выделение реплик на входе 16, 44,1 и 48 кГц. `npm run build` собрал клиент и сервер.
- На Mac M1 Pro реальный речевой сервис выдал WAV и распознал его обратно через HTTP. На тестовом сервере с отдельной базой прошёл сценарий: бриф, локальная озвучка вступления, прерывание, передача синтетической реплики про заказ в аптеке, вопрос, подтверждение воспроизведения и сохранение отчёта. Запросы анализа в этом сценарии получили тестовые ответы. Обнаружение границ реплики проверено в обработчике AudioWorklet на PCM.
- Собран Linux-образ речевого сервиса (arm64). Сеть отключена, корневая файловая система доступна только для чтения, веса смонтированы из проверенного кеша. Синтез и распознавание фразы «Расскажи, как ты проверил своё решение» прошли в контейнере. Конфигурация Compose с профилем speech валидна.
- Без ключа DeepSeek рабочее приложение сообщает `configured=false`, а `/health/ready` возвращает 503 даже при наличии старого ключа OpenAI.

## Открытые проверки

После подключения ключа отдельно проверены бриф, вопрос по тестовому кадру и отчёт в браузере. [Живой прогон](2026-11-23-deepseek-live-check.md)

Сквозной ручной созвон с физическим микрофоном, динамиками и демонстрацией экрана остаётся открытой проверкой. Нагрузочный прогон и стоимость реальной защиты на целевом сервере не измерялись.
