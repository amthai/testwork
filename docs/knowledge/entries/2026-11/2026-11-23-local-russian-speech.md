# Локальная проверка русской речи для Proof

## Контекст

В рабочей копии Proof браузер отправляет звук в OpenAI Realtime. Сессия использует события провайдера для обнаружения конца реплики, прерываний и очередности вопросов. Кандидаты на локальную обработку аудио проверялись отдельно от звонка.

## Модели

- Сбер публикует GigaAM-v3 под MIT. Для прогона выбран вариант E2E CTC с пунктуацией, экспортированный в ONNX INT8. [Карточка Сбера](https://huggingface.co/ai-sage/GigaAM-v3) · [Файлы экспорта](https://huggingface.co/csukuangfj/sherpa-onnx-nemo-ctc-punct-giga-am-v3-russian-2025-12-16)
- Для синтеза выбран голос Denis проекта Piper. У актуальной версии голоса русские данные и базовый голос rdh имеют лицензию CC0. Движок Piper распространяется под GPL-3.0. SHA-256 проверенных весов голоса `879bc365cb14d1380e3f5ed6044162ccf54c99f6161871569b7f830aec3ce841`. [Карточка голоса](https://huggingface.co/rhasspy/piper-voices/blob/main/ru/ru_RU/denis/medium/MODEL_CARD) · [Уточнение автора о версиях весов](https://github.com/OHF-Voice/piper1-gpl/issues/314) · [Piper](https://github.com/OHF-Voice/piper1-gpl)
- Сбер документирует синтез через SaluteSpeech с токеном доступа. В просмотренных официальных публикациях открытые веса отдельного синтезатора обнаружить не удалось. [SaluteSpeech](https://developers.sber.ru/docs/ru/salutespeech/guides/synthesis/synthesis-sync) · [Каталог команды](https://huggingface.co/ai-sage)

## Проверка

Apple M1 Pro, 16 ГБ. Piper 1.8.0 синтезировал моно WAV на 22 050 Гц. Для GigaAM звук приводился к 16 000 Гц. Распознавание выполнял sherpa-onnx 2.0.3 на CPU в три потока с 64 частотными полосами. Отсчёт времени начинался после загрузки моделей. Платные API в прогоне не вызывались.

| Вход | Наблюдение |
|---|---|
| «Как вы проверили, что пользователю стало проще оформить заказ?» | Piper сгенерировал 3,90 с звука за 0,53 с при первом вызове и за 0,12 с при повторном. GigaAM распознал все слова за 0,10 с, пропустил вопросительный знак. |
| «В Figma мы сравнили два варианта онбординга и запустили A/B-тест.» | После синтеза и распознавания все три термина исказились. В отдельной фразе после замены написания на «В Фигме» вернулось «В фильме». Для определения источника ошибок нужны отдельно записанные человеческие реплики и оценка озвучки на слух. |
| Тестовый файл example.wav из экспорта GigaAM | Обработаны 11,29 с записи за 0,28 с. Получена расшифровка на русском, точность по эталону не оценивалась. |

При совместной загрузке моделей и обработке одной реплики пиковый RSS процесса составил около 572 МиБ. В compose для веб-приложения выставлен лимит 512 МиБ. Для интеграции стоит выделить моделям отдельный сервис и проверить его на целевом сервере. Задержка от конца фразы кандидата до начала ответа интервьюера и работа с микрофона в браузере в этом прогоне не измерялись.
