# Границы текущего продукта

По поручению пользователя от 2026-09-06 mock-граница снята: в текущую реализацию входят OpenAI Realtime, сервер, сохранение материалов, реальные разборы, доступ по приглашению и история на устройстве. Основание — [спецификация рабочего сценария](../superpowers/specs/2026-09-06-live-product-design.md).

С 2026-11-23 доступен режим локальной речи и DeepSeek для вопросов и анализа изображений. [Спецификация](../superpowers/specs/2026-11-23-deepseek-local-voice.md).

В текущую версию не входят:

- аккаунты с восстановлением доступа и синхронизацией между устройствами;
- платежи, подписки и коммерческие тарифы;
- публичный неограниченный доступ к платному AI;
- Solve Session, совместное решение задания и visual workbench;
- обязательная загрузка файлов, импорт PDF/Figma и Figma-плагин; необязательные фото/скриншоты задания входят в текущую версию;
- автоматическое редактирование макетов;
- оценка эстетики UI, интонации по тексту и решение о найме;
- полная видеозапись и несколько участников;
- вакансии, резюме, портфолио;
- отдельный чат и мобильное приложение;
- горизонтальное масштабирование на несколько серверных реплик.

Оплата API и разрешение на публичный релиз — внешние условия запуска, не имитация интеграции. Расширение этих границ фиксируется отдельным продуктовым решением.
